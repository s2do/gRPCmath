# Milestone M1 — Unix Socket Bridge & Binary Operations

## Objective

Expand the nmath architecture by introducing a Unix domain socket bridge for local client communication and implement the first functional mathematical execution endpoint (`BinaryOperation`) utilizing a NumPy backend.

## Implemented

- `BinaryOperation` gRPC RPC
- Protocol Buffer enumerations for `Operator` and `OperationStatus`
- NumPy backend integration for floating-point arithmetic
- Unix domain socket bridge (`nmath-bridge`) 
- Regex-based expression parsing within the bridge
- Diagnostic `Ping` fallback for invalid expressions and server health checks
- Environment variable configuration via `.env` (`python-dotenv`)
- End-to-End full chain testing (CLI -> Socket -> Bridge -> gRPC -> Server -> NumPy)

## API

### `MathService.BinaryOperation`

Request:

    BinaryOperationRequest {
        left_operand: double
        right_operand: double
        operator: Operator (OPERATOR_ADD, OPERATOR_SUB, OPERATOR_MUL, OPERATOR_DIV)
    }

Response:

    BinaryOperationResponse {
        result: double
        status: OperationStatus (STATUS_SUCCESS, STATUS_DIV_BY_ZERO, STATUS_NAN, STATUS_ERROR)
    }

The M1 implementation returns the evaluated mathematical result as a double.

For example:

    BinaryOperationRequest(left_operand=3.0, right_operand=2.0, operator=OPERATOR_ADD)

produces:

    BinaryOperationResponse(result=5.0, status=STATUS_SUCCESS)

## Verification

The M1 test suite expands upon M0 by adding:

- E2E tests validating the full `Socket -> Bridge -> gRPC -> Server` chain
- Edge case testing for division by zero and invalid operators
- Exception handling and connection refusal tests for the socket client

Run:

    pytest --cov=nmath --cov-report=term-missing

## Out of scope

M1 does not implement:

- Complex AST parsing (e.g., expressions with multiple operators like `3 + 2 * 5`)
- Advanced mathematical functions (trigonometry, exponentiation, matrix algebra)
- Persistence and calculation history
- Authentication
- Production deployment
