# Milestone M0 — gRPC Connectivity

## Objective

Establish the basic nmath client/server architecture and verify that a
Python client can communicate with the server through gRPC.

## Implemented

- Python package structure
- Protocol Buffer definition
- `MathService` gRPC service
- `Ping` RPC
- gRPC server
- Python gRPC client
- `nmath` CLI
- Server/client integration
- Unit tests
- Contract tests
- CLI tests

## API

### `MathService.Ping`

Request:

    PingRequest {
        message: string
    }

Response:

    PingResponse {
        message: string
    }

The M0 implementation returns:

    pong: <message>

For example:

    PingRequest(message="hello")

produces:

    PingResponse(message="pong: hello")

## Out of scope

M0 does not implement:

- mathematical operations
- NumPy-backed execution
- expression parsing
- job execution
- persistence
- authentication
- production deployment
